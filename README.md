#  **Tugas Besar Object Oriented Programming IF2010 K2 Kelompok N**
_______

## Description
_______

Nimon's Cooked adalah permainan simulasi memasak dengan tema manajemen waktu yang sangat terinspirasi oleh *game* populer *Overcooked*. Permainan ini menantang pemain untuk menyiapkan, memproses, dan merakit bahan baku menjadi burger dalam waktu terbatas.

Proyek ini dikembangkan menggunakan Java Swing dan berfokus pada penerapan  **Object-Oriented Programming (OOP)** yang kuat, seperti Polimorfisme, Inheritance, dan penggunaan *Design Pattern* untuk membangun arsitektur game yang modular dan terstruktur.

##  How to Run
_______
Ikuti langkah-langkah di bawah ini untuk mengkompilasi dan menjalankan program di lingkungan lokal Anda.

1. Instalasi __Gradle for Java__ pada IDE
2. *Clone repository* ini (https://github.com/shinjimiami/TUBES-OOP-KEL-N.git)  
3. Buka *command prompt* atau terminal
4. Jalankan program dengan menggunakan
``` ./gradlew run ```
